# 🧠 Assignment 4 Reflection

## 📌 Challenges Faced

One major challenge was integrating the holidays data. Instead of using a static dataset,
I used the `python-holidays` library, which required understanding how to dynamically
generate holiday dates and align them with the dataset.

Another issue was ensuring the Gold dataset was properly updated after adding new features,
as missing columns caused errors in the Streamlit app.

---

## ⚠️ Assumptions

- Returns are approximately normally distributed
- Observations are independent
- Holiday effects are consistent across years

---

## 🚫 Limitations

- Crypto markets operate 24/7, so holidays may not strongly influence trading
- Data is observational, so causation cannot be inferred
- External factors (news, macroeconomics) are not included

---

## 📈 What I Learned

- How to extend a data pipeline with new data sources
- How to apply statistical tests in real-world scenarios
- Importance of interpreting results, not just computing them
- Difference between correlation and causation

---

## 🎯 Future Improvements

- Add more external data (Google Trends, macro indicators)
- Improve visualization using advanced libraries
- Include machine learning models for prediction

---

## ✅ Conclusion

This assignment helped bridge the gap between data engineering and statistical analysis,
demonstrating how structured data can support meaningful insights.
